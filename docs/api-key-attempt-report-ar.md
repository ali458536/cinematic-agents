وبالتالي **جدول المرشحين ما زال فارغاً — صفر مرشّح.** لن أملأه بأسماء من
الذاكرة، التزاماً بقاعدتك من البداية.

## الموانع الثلاثة — بالأدلة

### المانع ١: أداة `claude-in-chrome` غير متصلة بهذه الجلسة

بحثت في سجل أدوات الجلسة مرتين وبصيغتين مختلفتين:

- بحث عن `claude-in-chrome` → **"No matching deferred tools found"**
- بحث عن `chrome browser tab navigate click screenshot type keyboard`
  → أعاد أدوات غير ذات صلة إطلاقاً (GitHub، DesignSync، WebFetch) — **لا أداة
  تحكّم بمتصفح**

**هذه نقطة مهمة يجب توضيحها:** أداة `claude-in-chrome` — لو كانت متصلة — هي
التي تقود متصفح Chrome **الخاص بك أنت**، وبالتالي كانت ستحمل جلسة دخولك لگوگل
فعلاً. لكنها ببساطة **غير مسجَّلة في هذه الجلسة**، فلا يوجد ما أقوده.

### المانع ٢: `console.cloud.google.com` محجوب بسياسة الشبكة

اختُبر بطريقتين مستقلتين:

**طلب HTTP مباشر:**
```
https://console.cloud.google.com/        -> 000  (فشل الاتصال)
https://console.developers.google.com/   -> 000  (فشل الاتصال)
https://accounts.google.com/             -> 302  (يعمل)
https://www.googleapis.com/              -> 404  (يعمل — استجابة صحيحة لجذر فارغ)
```

**متصفح Chromium حقيقي عبر Playwright:**
```
https://console.cloud.google.com/                  -> ERR_TUNNEL_CONNECTION_FAILED
https://console.cloud.google.com/apis/credentials  -> ERR_TUNNEL_CONNECTION_FAILED
```

لاحظ المفارقة: `accounts.google.com` و`googleapis.com` يعملان، لكن **الكونسول
نفسه مرفوض**. أي أنه حتى بمتصفح شغّال، صفحة `apis/credentials` لن تُفتح.

### المانع ٣: المتصفح الاحتياطي هنا لا يحمل حسابك أصلاً

المتصفح الوحيد المتاح لي هو Chromium يعمل **داخل هذه الحاوية المعزولة**، لا على
جهازك. فحصت وجود أي ملف تعريف مسجَّل دخول:

```
~/.config/google-chrome  -> غير موجود
~/.config/chromium       -> غير موجود
~/.mozilla               -> غير موجود
بحث عن ملفات Cookies     -> لا نتائج
```

ملف تعريف فارغ تماماً، صفر كوكيز گوگل. حتى لو رُفع الحجب في المانع ٢، هذا
المتصفح كان سيفتح الكونسول **مسجَّل خروج**، وسيطلب بريدك وكلمة مرورك — وهذا ما
منعتَه صراحة ولن أقترب منه.

## الحل: دقيقة واحدة من طرفك، ثم أكمل أنا كل شيء

الخبر الجيد: **`www.googleapis.com` متاح** من هنا. يعني السكربت سيشتغل فوراً
بمجرد وجود المفتاح — **لا يحتاج فتح يوتيوب ولا فتح الكونسول**. الناقص هو
المفتاح فقط.

### الخطوات من جهازك (٣ ضغطات)

1. افتح `console.cloud.google.com/apis/credentials`
2. تأكد أن المشروع المختار أعلى الصفحة هو **"Gemini API"**
3. **+ CREATE CREDENTIALS** ← **API key** ← انسخ المفتاح

### كيف توصّله لي — الطريقة الآمنة (موصى بها)

أضفه كمتغيّر بيئة في إعدادات البيئة، لا في المحادثة:

```
الاسم:  YOUTUBE_API_KEY
القيمة: <المفتاح>
```

(إعدادات بيئة Claude Code on the web ← Environment variables)

هكذا لا يظهر المفتاح في نص المحادثة إطلاقاً، وألتقطه تلقائياً وأشغّل السكربت.

### إن لصقته بالمحادثة بدل ذلك

سيشتغل، لكنه سيبقى محفوظاً في سجل المحادثة. لو اخترت هذا، **قيّد المفتاح بعد
الانتهاء** (Restrict key ← YouTube Data API v3 فقط) أو احذفه وأنشئ غيره لاحقاً.

### ما سأفعله فور وصول المفتاح

```
python3 scripts/yt_cc_business_search.py --out out/
```

- بحث بـ ١٥ صيغة (عربية + إنجليزية) بفلتر `videoLicense=creativeCommon`
- تحقّق كل فيديو من سجلّه الخاص: `status.license == "creativeCommon"`، وحذف
  كل ما لم يؤكّده سجلّه
- تصفية الصلة بموضوع المال/الأعمال بشكل مستقل عن الترخيص
- ترتيب حسب الحجم × النشاط
- تسليم `out/candidates.md` و`out/candidates.json` + التقرير النهائي

وأؤكد لك حفظ المفتاح بذكر آخر ٤ أحرف منه فقط، كما طلبت.
